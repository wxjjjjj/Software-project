# Carpooling App(手机私家车拼车软件)

本项目为同济大学2023级计算机科学与技术专业软件工程课程设计。

本项目是一个基于 **Flask (Python 3.9)** 后端与 **Vue 3** 前端的拼车平台。项目涵盖账号管理、订单匹配、支付模拟与用户反馈等核心功能。系统采用**微服务架构**，按功能域拆分为三个独立服务，通过网关统一对外暴露接口。

## ✨ 功能特性

系统按角色划分主要功能，同时遵循**三个功能域**的微服务拆分：

### 1. 拼车人功能

- **注册与登录**：默认注册为拼车人身份，支持密码登录。
- **发布拼车订单**：填写出发地、目的地、出发时间段、人数需求，并可选择标签（如“宠物友好”、“静音”、“禁烟”等）。
- **订单搜索与参与**：按目的地、出发地、时间段等条件搜索已发布的订单，选择加入其他拼车人的订单。
- **支付订单**：模拟支付（不接入真实支付渠道），自动计算分摊金额并完成扣款。
- **互动反馈**：向管理员提交反馈/投诉，查看处理结果。

### 2. 车主功能

- **车主认证**：在个人中心提交车辆信息（车牌、车型、座位数等），等待管理员审核。
- **车辆信息管理**：认证通过后，维护名下车辆（增删改查、设置可用/停用状态）。
- **接单**：浏览拼车人发布的订单，选择接单（车主只能接单，不能主动发布订单）。
- **收款提现**：查看钱包余额，发起提现申请（模拟提现流程）。
- **互动反馈**：与拼车人即时沟通，或向管理员发起投诉。

### 3. 管理员功能

- **内置管理员账号**：数据库预置，无法通过注册获得管理员权限。
- **用户账号管理**：查看所有用户，停用/恢复拼车人或车主身份（信誉积分独立管理）。
- **拼车订单管理**：查看、干预异常订单（如强制取消、退款）。
- **反馈信息管理**：处理用户提交的反馈与投诉，记录处理结果。



## 🛠️ 技术栈

- **后端**：Python 3.9 + Flask + SQLAlchemy
- **前端**：Vue 3 + Vite + Axios
- **数据库**：MySQL (同时支持真实数据库运行和Mock模式，即无数据库运行)
- **服务治理**：网关模式 (端口 8000)，三个微服务分别运行在 8001、8002、8003

## 📂 项目结构

```text
/
├── backend/                 # 后端微服务

│   ├── ride_service/        # 订单与车辆域（端口 8002）
│   ├── ops_service/         # 交易运营域（端口 8003）
│   ├── gateway/             # 统一网关（端口 8000）
│   ├── scripts/             # 启动脚本
│   ├── requirements.txt
│   └── .env                 # 数据库连接配置（需自行创建）
├── frontend/                # Vue 3 前端
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── ...
├── sql/                     # 建库建表 SQL 脚本
├── docs/                    # 开发文档
└── README.md                
```
