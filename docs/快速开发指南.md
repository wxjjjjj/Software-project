# 快速开发指南


- clone后，在自己电脑独立开发本域前后端
- 前端默认连本机网关（8000），联调时可一键切到组长地址
- 未开发完成的域使用 mock 返回
- 后端目录分工先看：`backend/STRUCTURE.md`。

## 首次拉取后

### 后端
1. 进入backend目录。
2. 执行：`pip install -r requirements.txt`
3. 执行：`./scripts/bootstrap_env.ps1`（自动创建 backend/.env）
4. 按自己pc上的数据库修改 backend/.env（只改你负责的域也可以）。
5. 启动全部服务：`./scripts/run_services.ps1`

### 前端
1. 进入frontend目录。
2. 执行：`npm install`
3. 直接编辑 `frontend/.env`
4. 默认 `VITE_USE_LEADER_API=false`（连本机 8000）
5. 启动：`npm run dev`

## 三个进程端口约定
- 账号域服务：8001
- 订单域服务：8002
- 运营域服务：8003
- 网关服务：8000（前端访问后端经过8000，然后由main.py分发到不同服务）

前端始终只连网关 8000。

## 每个域主要改哪些文件
- 账号域wyx：
  - backend/account/account_domain.py
  - backend/account/service.py
  - docs/apis/account.md
  - sql/account/*
- 订单域hws、zj：
  - backend/ride/ride_domain.py
  - backend/ride/service.py
  - docs/apis/ride.md
  - sql/ride/*
- 运营域yzr：
  - backend/ops/ops_domain.py
  - backend/ops/service.py
  - docs/apis/ops.md
  - sql/ops/*

## mock与真实数据库切换
在 backend/.env 中：
- ACCOUNT_USE_MOCK=true/false
- RIDE_USE_MOCK=true/false
- OPS_USE_MOCK=true/false

建议：
- 开发初期先 true（快速联调）
- 本域功能稳定后改 false 接真库

## SQL迁移提交规则
- 按域目录提交：
  - sql/account
  - sql/ride
  - sql/ops
- 每次提交SQL必须在提醒我（wxj）更新集成环境数据库。

## 联调开关（前端）
- `VITE_USE_LEADER_API=false`：连自己本机网关
- `VITE_USE_LEADER_API=true`：连组长集成环境网关

## Q&A
- Q: 某个域没完成，是否会影响他人？
- A: 不会。该域先返回 mock，其他域可以继续联调。

- Q: 前端要连哪个服务端口？
- A: 只连 8000 网关，永远不要直连 8001/8002/8003。
