## 当前状态

- 交易运营域已经合并为 `backend/ops`。
- 当前支持支付、钱包、提现、聊天、投诉、管理员统计和提现审核。
- 投诉接口统一使用 `/api/complaints` 和 `/api/admin/complaints`。
- 个人中心不再提供独立反馈页面；投诉从订单详情或用户资料页进入。
- 订单 ID 支持字符串形式，可与订单车辆域的订单 ID 对齐。
- Mock 与数据库模式由 `OPS_USE_MOCK` 控制，数据库模式不会自动混入 Mock 数据。

## 历史意义

该阶段把支付、钱包、聊天和投诉能力接入项目，为订单详情中的支付、聊天和投诉入口提供了运营域支撑。
