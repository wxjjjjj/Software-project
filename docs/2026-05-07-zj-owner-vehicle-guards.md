# 车主车辆管理与接单校验补充

## 修改范围

- 后端：`backend/ride/service.py`、`backend/ride/ride_domain.py`
- 前端：`frontend/src/api/ride.js`、`frontend/src/router/index.js`、`frontend/src/views/owner/OwnerVehicleForm.vue`、`frontend/src/views/owner/OwnerOrderAvailable.vue`

## 功能说明

### 1. 车主身份判断

- 前端车辆管理路由 `/me/vehicles`、新增、编辑、认证资料提交均增加 `ownerRequired` 标记。
- 未完成车主身份认证的用户访问车辆管理页面时，会被引导到 `/me/driver-application`。
- 前端请求头统一携带 `X-Owner-Verified`，后端车辆管理和接单接口会根据该头进行身份门禁。
- 后端车辆列表、新增、编辑、启停、删除、车辆认证申请、接单接口均要求车主身份已认证。

### 2. 车牌号规范检测

- 后端新增车牌号正则校验，新增或编辑车辆时统一校验并标准化为大写。
- 前端新增同规则校验，提交前拦截明显不规范的车牌号。
- 支持普通 7 位和新能源 8 位大陆车牌格式，例如 `沪A12345`、`沪AD12345`。

### 3. 车辆型号输入联想

- 车辆表单的“品牌型号”字段新增候选列表。
- 输入任意一个字符后，会展示匹配的完整车型；点击候选项可直接回填。
- 默认候选覆盖常见车型，如比亚迪、特斯拉、丰田、本田、大众、日产等。

### 4. 接单车辆状态强校验

- 后端接单仍以服务端校验为准：必须是当前用户本人车辆、车辆已认证、车辆状态为 `available`。
- 即使用户车主身份已认证，也不能使用未认证、禁用或非本人车辆接单。
- 前端接单弹窗会先过滤车辆，并修正字符串 `"0"` / `"false"` 被误判为已认证的问题。

## 兼容说明

- 管理员车辆认证审核接口保持原有管理员权限逻辑，不受车主身份门禁影响。
- 车辆编辑现在同时兼容数据库数字 ID 和 mock/UUID 字符串 ID。
