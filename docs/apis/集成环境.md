# 集成环境说明

## 总述

集成环境用于统一联调前端、网关、三域服务和三套数据库。前端只连接网关地址，所有跨域访问均通过 API 文档约定的 `/api` 路径完成。

## 服务地址

| 服务 | 本地默认端口 | 说明 |
|------|--------------|------|
| Gateway | 8000 | 前端唯一后端入口 |
| Account | 8001 | 账号域 |
| Ride | 8002 | 订单车辆域 |
| Ops | 8003 | 交易运营域 |
| Frontend | 5173 | Vite 开发服务器 |

前端代理配置位于 `frontend/vite.config.js`：

- `/api` 转发到网关。
- `/amap` 转发到高德地图 REST API。
- `VITE_USE_LEADER_API=true` 时使用 `VITE_API_TARGET_LEADER`。
- `VITE_USE_LEADER_API=false` 时使用 `VITE_API_TARGET_LOCAL`。

## 数据库

| 数据库 | 负责域 | SQL 目录 |
|--------|--------|----------|
| `account_db` | 账号域 | `sql/account` |
| `ride_db` | 订单车辆域 | `sql/ride` |
| `ops_db` | 交易运营域 | `sql/ops` |

每个域只维护自己的数据库表。跨域信息通过 HTTP API 读取，不直接跨库查询。

## 初始化建议

真实数据库模式只执行建表脚本：

```powershell
mysql -u root -p < sql/account/001_init.sql
mysql -u root -p < sql/ride/001_init.sql
mysql -u root -p < sql/ops/001_init.sql
```

演示/白盒测试时才导入 seed：

```powershell
mysql -u root -p account_db < sql/account/002_seed.sql
mysql -u root -p ride_db < sql/ride/002_seed.sql
mysql -u root -p ops_db < sql/ops/002_seed.sql
```

特别注意：`sql/ride/002_seed.sql` 会向数据库写入演示订单和车辆。一旦导入，这些行就是数据库数据，不属于 Mock 兜底。若数据库模式不希望展示演示订单，不要导入该脚本，或清理 `ord-seed-*` 等演示行。

## Mock 开关

`backend/.env`：

```env
ACCOUNT_USE_MOCK=true
RIDE_USE_MOCK=false
OPS_USE_MOCK=true
```

- Mock 模式用于无数据库联调。
- 数据库模式使用 MySQL 实际数据，不自动混入 Mock 数据。
- Ride 写操作在数据库模式下要求真实 `X-User-Id`，缺失会返回 `401 missing X-User-Id`。
