# 集成环境

## 总述
wxj维护一套常开集成环境。

每个人只提交代码和 SQL 迁移。

前端统一连接一个后端地址，便于联调。

必需接口返回字段与API文档一致，跨库调用api时均以API文档为准

当然每个人开发自己的数据库时为了验证sql的正确性，得在自己电脑上有自己建立的数据库。涉及到跨数据库的信息时联系我，然后我这边开启服务就可以跨库获取信息（每个人数据库的修改都应该和我及时同步）

## 服务
- 网关/API 地址: http://<wxj主机>:8000
- 数据库:
  - account_db
  - ride_db
  - ops_db

- 按功能域存放目录:
  - sql/account
  - sql/ride
  - sql/ops
